BELLA FORNO — Luxury Italian Pizza Website
===========================================

الملفات:
- index.html : الصفحة الرئيسية والأقسام.
- style.css  : التصميم والتجاوب وتأثيرات CSS ثلاثية الأبعاد.
- script.js  : الحركة والتفاعلات والفلاتر ونموذج الحجز التجريبي.

التشغيل:
1) فك ضغط الملف.
2) افتح index.html في المتصفح، أو ارفع المجلد إلى استضافة static مثل Firebase Hosting / GitHub Pages.

قبل النشر:
- استبدل العنوان ورقم الهاتف وبيانات التواصل الوهمية في قسم "زيارتنا".
- أضف روابط حسابات التواصل الاجتماعي الصحيحة.
- اربط نموذج الحجز بخدمة خلفية أو Firebase/خدمة حجوزات؛ النموذج الحالي تجريبي ولا يرسل البيانات إلى المطعم.
- الصور والخطوط الحالية تُحمّل من الإنترنت، لذلك يلزم اتصال إنترنت لظهورها.

ملاحظة:
الهوية البصرية تستخدم CSS 3D وparallax وتأثيرات ظهور وحركة، وليست مشهد WebGL/Three.js.
الأسعار والأطباق أمثلة قابلة للتعديل.

تحديث الخلفية السينمائية:
- تمت إضافة صورة بيتزا كبيرة كخلفية ثابتة تغطي الموقع، مع طبقات تعتيم حتى يظل النص والمنيو واضحين.
- الخلفية تتحرك بحركة بطيئة جدًا لإحساس سينمائي.
- الصورة تُحمّل من Unsplash عبر الإنترنت. يمكن استبدال رابطها في .backdrop-image داخل style.css.

تحديث الهوية: تم تحويل ألوان الموقع إلى لوحة كريمية/عاجية دافئة مع لمسات ذهبية، وتفتيح الخلفية والبطاقات والنماذج للحفاظ على وضوح النص.
